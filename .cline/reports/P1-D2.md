# P1-D2: IPC Bridge — Implementation Report

## Task Summary

Implemented `ipc_bridge.rs`: two async tasks per worker — (1) stdin writer that serializes `WorkerMessage` from an mpsc channel to framed bytes on the worker's stdin, and (2) stdout reader that deserializes framed bytes into `WorkerEvent` and broadcasts them. On pipe close: mark worker `Dead`, schedule respawn after 2s delay.

## Implementation Details

### 1. New Module: `ipc_bridge.rs`

**A. `spawn_stdin_writer(worker_id, stdin)`**
- Creates an internal mpsc channel (capacity 64)
- Spawns a background task that receives `WorkerMessage` values and writes them via `framing::write_message()` to the subprocess stdin
- On write error or channel close: logs and exits gracefully
- Returns `(tx, JoinHandle<()>)`

**B. `spawn_stdout_reader(worker_id, stdout, child, event_tx, workers_ref, respawn_fn, device)`**
- Reads framed bytes from stdout using `framing::read_message()` (inline implementation for performance)
- Deserializes into `WorkerEvent`, broadcasts via `event_tx`
- Handles state transitions: Ready → Idle, Dying → Dead
- On pipe close: marks worker Dead with exit status reason
- Invokes respawn closure after 2s delay if provided

### 2. `managed.rs` Changes

Added three new fields to `ManagedWorker`:
```rust
pub msg_tx: Option<mpsc::Sender<WorkerMessage>>,
pub stdin_reader_handle: Option<JoinHandle<()>>,
pub stdout_reader_handle: Option<JoinHandle<()>>,
```

### 3. `pool.rs` Changes

- **spawn_for_device()**: Extracted inline stdout reader into `ipc_bridge::spawn_stdout_reader()`, added stdin writer via `ipc_bridge::spawn_stdin_writer()`
- **send_to()**: Replaced stub with actual mpsc-based sending through `worker.msg_tx`
- **Respawn logic**: Closure captures Arc references to workers map, event tx, python bin, worker script — spawns a new subprocess on pipe close after 2s delay
- **shutdown_all()**: Sends Shutdown message to each worker before marking dead

### 4. `lib.rs` Changes

Added `pub mod ipc_bridge;`

## Architecture Decisions

1. **Respawn closure**: Used Option<Box<dyn FnOnce>> pattern — captures Arc references to pool internals, avoids borrow checker issues with `spawn_for_device(&self)`
2. **No Weak references**: Simpler than Weak reference approach — closure owns its data via cloned Arc fields
3. **Inline framing in stdout reader**: Kept the proven frame-by-frame reading logic inline for performance (avoids extra async boundary)
4. **Internal mpsc channel in stdin writer**: Caller doesn't need to manage channel creation — `spawn_stdin_writer` creates and returns both ends
