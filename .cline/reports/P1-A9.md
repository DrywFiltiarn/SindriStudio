# P1-A9 — anvilml-hardware: mock implementation

**Status:** COMPLETE ✅

## Summary

Implemented `MockHardwareDetector` behind the `mock-hardware` feature flag. The detector reads three environment variables (`ANVILML_MOCK_DEVICE_TYPE`, `ANVILML_MOCK_VRAM_MIB`, `ANVILML_MOCK_GFX_ARCH`) and returns a single fake `GpuDevice` with configured values. Used by all CI tests to avoid requiring real GPU hardware.
