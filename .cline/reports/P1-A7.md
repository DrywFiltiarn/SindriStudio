## Risks / Edge Cases Handled

1. **rocm-smi JSON format variation**: `extract_vram_mib` handles both direct string and nested object formats
2. **lspci requires root**: ReBAR detection returns `false` on unprivileged systems rather than erroring
3. **rocminfo output is unstructured text**: Regex-based parsing returns `None` for `gfx_arch` if format changes
4. **Cross-platform**: ROCm is primarily Linux; `lspci` is Linux-only — Phase 1 focuses on Linux only
