## Task Summary

## Implementation Details

### Files Created
1. **`backend/worker/ipc.py`** — Two public functions:
   - `read_message() -> dict`: Reads 4-byte BE u32 length prefix + msgpack body from `sys.stdin.buffer`. Raises `EOFError("supervisor closed stdin")` on short read.
   - `write_event(event: dict) -> None`: Serializes event with `msgpack.packb(use_bin_type=True)`, writes 4-byte BE u32 length prefix + body to `sys.stdout.buffer`, calls `flush()`.

2. **`backend/worker/tests/conftest.py`** — Autouse fixture setting `ANVILML_WORKER_MOCK=1` for all worker tests, with proper restoration of original env value.

3. **`backend/worker/tests/test_ipc.py`** — 13 tests across 4 test classes:
   - `TestWriteEventFraming` (4 tests): prefix+body correctness, flush called, empty dict, nested dict
   - `TestReadMessageRoundTrip` (4 tests): simple event, complex Execute event, full Ready event, consecutive messages
   - `TestReadMessageErrors` (3 tests): EOF on empty stdin, EOF on partial prefix (< 4 bytes), EOF on truncated body
   - `TestEndToEndRoundTrip` (2 tests): write→read round-trip for Ready event, multi-event round-trip
