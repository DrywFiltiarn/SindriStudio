Implement all shared domain types in `anvilml-core/src/types/`:

3. **`test_job_roundtrip`** (job.rs) — Create a `Job` with all fields, serialize to JSON via `serde_json`, deserialize back, assert equality

4. **`test_ws_event_discriminated_union`** (events.rs) — Serialize a `WsEvent::JobQueued` to JSON, assert the `"type"` field is `"JobQueued"`, deserialize back

5. **`test_dtype_serialization`** (model.rs) — Assert `DType::Bfloat16` serializes to `"bfloat16"`

6. **`test_worker_status_serialization`** (worker.rs) — Assert each `WorkerStatus` variant serializes correctly (initializing, idle, busy, unresponsive, dead)

7. **`test_submit_job_request_roundtrip`** (job.rs) — Create a `SubmitJobRequest`, serialize and deserialize, assert workflow and settings preserved

8. **`test_hwinfo_primary_device`** (hardware.rs) — Create `HardwareInfo` with mixed devices (Rocm + Cpu), verify `primary_device()` returns the non-CPU device

### Architecture Decisions

1. **`ModelKind` re-export**: `config.rs` already defines `ModelKind` (P1-A3). `model.rs` uses `config::ModelKind` directly rather than duplicating. The `types/mod.rs` re-exports it for convenience.

2. **`WsEvent` discriminated union**: Uses `#[serde(tag = "type")]` so the JSON discriminator field name is the variant name (e.g., `"JobQueued"`). This matches the API_CONTRACT.md where each event has a `"type"` field.

3. **`serde_json::Value` for workflow**: The workflow field is a generic JSON object (DAG nodes/edges). Using `serde_json::Value` avoids premature schema constraints; validation happens in the scheduler.

4. **`chrono::DateTime<Utc>` for all timestamps**: ISO 8601 UTC format per API_CONTRACT.md conventions. `serde` handles the `"2025-01-15T14:30:00.000Z"` format natively.

5. **`Option<T>` for nullable fields**: `started_at`, `completed_at`, `error`, `worker_id`, `sha256`, `busy_with_job`, `pid` are all `Option<T>` since they are not set until the job lifecycle progresses.

### Deviations from Plan

1. **`utoipa` features**: Added `chrono` and `uuid` features to `utoipa` dependency to enable `ToSchema` implementations for `DateTime<Utc>` and `Uuid` types.
2. **`ModelKind`**: Added `ToSchema` derive to `ModelKind` in `config.rs` since `ModelMeta` references it.
3. **`DeviceType::Ipx`**: Added `#[serde(rename = "ipex")]` to the `Ipx` variant to serialize as `"ipex"` as specified in the plan.
4. **`WsEventBase`**: Removed `type_` field from `WsEventBase` — the enum's `#[serde(tag = "type")]` handles the discriminator, and including `type_` in the flattened base would cause a "duplicate field `type`" serialization error.
