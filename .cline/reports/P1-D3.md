# Task Report: P1-D3

## Summary

Implemented per-device environment variable injection for Python worker processes in `anvilml-worker`. Created a new `env.rs` module with pure functions that build the full environment map for each device type (ROCm, CUDA, IPEX, CPU), following the ENVIRONMENT.md specification.

## Files Created

- **`crates/anvilml-worker/src/env.rs`** — 452 lines. Contains:
  - `build_worker_env(device: &GpuDevice, config: &ServerConfig) -> HashMap<String, String>` — main entry point
  - `build_base_env()` — common vars for ALL device types (threading, ANVILML_WORKER_MOCK)
  - `build_rocm_env()` — ROCm-specific vars from ENVIRONMENT.md (HIP_VISIBLE_DEVICES, ROCM_HOME/PATH, ROCBLAS_USE_HIPBLASLT, HSA_OVERRIDE_GFX_VERSION, etc.)
  - `build_cuda_env()` — CUDA-specific vars (CUDA_VISIBLE_DEVICES, PYTORCH_CUDA_ALLOC_CONF)
  - `build_ipex_env()` — IPEX-specific vars (ONEAPI_DEVICE_SELECTOR=level_zero:)
  - 16 unit tests covering all device types and conditional env vars

## Files Modified

- **`crates/anvilml-worker/src/lib.rs`** — Added `pub mod env;` to export the new module
