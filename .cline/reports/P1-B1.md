# P1-B1 — anvilml-registry: model scanner — Report

## Summary

Implemented the model scanner and in-memory registry for the AnvilML project.
The scanner walks filesystem directories recursively, discovers model weight files,
and produces `ModelMeta` structs. The registry provides an in-memory store with
lookup, filtering, and VRAM estimation capabilities.

## Implementation Details

### Scanner (`scanner.rs`)
- **Recursive walking**: Uses `walkdir::WalkDir` to traverse directories
- **File filtering**: Only includes `.safetensors`, `.gguf`, `.pt`, `.bin` extensions
- **ID generation**: `sha256(relative_path)` → hex encode → first 12 chars
- **Dtype inference**: Case-insensitive filename keyword matching (fp16, bf16, f32, int8)
- **SHA256 field**: Always `None` at scan time (lazy computation per spec)
- **VRAM estimate heuristic**: Float32×1.0, Float16/Bfloat16×0.5, Int8×0.25, Unknown×0.5

### Registry (`registry.rs`)
- **HashMap-backed** storage keyed by stable model ID
- **scan_and_load**: Populates registry from ModelDirConfig list (idempotent)
- **list**: Optional filtering by ModelKind
- **get**: Single model lookup by ID
- **count**: Total model count
- **estimate_vram_mib**: Delegates to scanner heuristic
