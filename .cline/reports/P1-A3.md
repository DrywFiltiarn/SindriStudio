2. **`test_env_var_override`** — Set `ANVILML_PORT=9999` env var, call `ServerConfig::load()`, assert port is 9999

### Config Loading Strategy

Use the `config` crate with a two-source chain:

1. **File source**: Read `anvilml.toml` from the current working directory (or configurable path)
2. **Environment source**: Override with `ANVILML_*` env vars using `_` as separator (e.g., `ANVILML_PORT`, `ANVILML_HOST`, `ANVILML_ROCM_TARGET_GFX`)

The `config` crate handles the nested key mapping automatically:
- `ANVILML_ROCM_TARGET_GFX` → `rocm.target_gfx`
- `ANVILML_HARDFORCE_DEVICE_TYPE` → `hardware.force_device_type`

For `model_dirs` (array of tables), the `config` crate maps `ANVILML_MODEL_DIRS_0_PATH`, `ANVILML_MODEL_DIRS_0_KIND`, etc.
