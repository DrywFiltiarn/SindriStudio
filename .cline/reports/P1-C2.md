## Implementation Details

### worker_main.py
- **CLI args**: `--worker-id` (required), `--device-index` (default: 0)
- **Mock mode** (`ANVILML_WORKER_MOCK=1`): skips torch import entirely, uses fake defaults
- **Real mode**: sets OMP/MKL env vars before torch import, then detects device and queries VRAM
- **Startup sequence**: threading env → device detection → VRAM query → Ready event emission
- **IPC read loop**: handles Ping→Pong, Shutdown→exit(0), Execute→placeholder error, unknown→error
- All diagnostic output goes to stderr; events go to stdout via IPC framing
