### Key Design Decisions

#### 1. `HardwareError` type
```rust
#[derive(Error, Debug)]
pub enum HardwareError {
    #[error("device detection failed: {0}")]
    Detection(String),
    #[error("io error: {0}")]
    Io(#[from] std::io::Error),
    #[error("hardware error: {0}")]
    Other(String),
}
```
Using `thiserror` for ergonomic error display. `#[from] std::io::Error` for I/O operations.

#### 2. `DeviceDetector` trait
```rust
#[async_trait]
pub trait DeviceDetector: Send + Sync {
    async fn detect(&self) -> Result<Vec<GpuDevice>, HardwareError>;
    fn device_type(&self) -> DeviceType;
}
```
- `async fn detect()` — returns a `Vec<GpuDevice>` (supports multi-device per backend)
- `fn device_type()` — returns the `DeviceType` this detector is for
- `Send + Sync` — required so detectors can be stored behind `Arc` and used across threads

#### 3. `CpuDetector` implementation
- Always succeeds (never returns `Err`) — CPU is always available
- Uses `sysinfo::System` to get total RAM, CPU model, core counts
- Returns exactly one `GpuDevice` with:
  - `device_type: DeviceType::Cpu`
  - `vram_total_mib` = total system RAM in MiB
  - `vram_free_mib` = available RAM in MiB
  - `vram_used_mib` = 0
  - `name` = CPU model string
  - `gfx_arch`, `driver_version`, `rebar_enabled` = None/false
  - `capabilities` = all false (CPU has no GPU inference capabilities)
- `HostInfo` is built from the same sysinfo data

#### 4. `detect_all_devices(config)` public function
```rust
pub async fn detect_all_devices(config: &HardwareOverrideConfig) -> Result<HardwareInfo>
```
- If `config.force_device_type == Some("cpu")`: only run `CpuDetector`, skip all GPU detectors
- Otherwise: instantiate all available detectors (CPU always included), run `detect()` on each, merge results
- Build `HardwareInfo` from merged devices + host info
- Apply `HardwareInfo::primary_device()` logic (already implemented in core)

## Design Decisions

### 1. `sysinfo` crate choice
`sysinfo` is the standard Rust crate for cross-platform system information. It supports Linux, Windows, and macOS. It provides:
- `System::new_all()` — refresh all system info
- `System::total_memory()` — total RAM in bytes → convert to MiB
- `System::available_memory()` — free RAM in bytes
- `System::cpu_name()` — CPU model string
- `System::physical_core_count()` / `System::logical_cpu_count()` — core/thread counts
- `System::cpu_usage()` — per-CPU usage (average for host)

### 2. `async-trait` vs `async fn` in trait
The task spec explicitly uses `#[async_trait]` in the trait definition. `async-trait` is needed because Rust does not yet support `async fn` in traits natively (async fn in traits is stable since Rust 1.75 but requires `#![feature(trait_upcasting)]` or the new default method syntax; `async-trait` is the established, widely-used approach).

### 3. `HardwareInfo` construction
`detect_all_devices` constructs `HardwareInfo` by:
1. Creating `CpuDetector` (always)
2. Collecting all `GpuDevice` results into `devices` Vec
3. Building `HostInfo` from `CpuDetector::host_info()` or from sysinfo directly
4. Returning `HardwareInfo { host, devices }`

### 4. Error handling
- `HardwareError::Detection(String)` — for detection failures (e.g., process spawn error)
- `HardwareError::Io(#[from] std::io::Error)` — for I/O errors from sysinfo
- `HardwareError::Other(String)` — for unexpected errors
- `detect_all_devices` returns `anyhow::Result<HardwareInfo>` — top-level error type for the public API

### 5. CPU as "GPU device"
Per the architecture doc, CPU is listed as a valid compute device with its own entry in `DeviceType`. The `GpuDevice` struct is reused for CPU (it's a general "compute device" concept, not strictly GPU). CPU devices have:
- `vram_total_mib` = total system RAM (the "VRAM" equivalent for CPU)
- `capabilities` = all false (no GPU-specific features)
- `gfx_arch` = None

#### 2c. Create `src/detector.rs`
```rust
use anyhow::Result;
use async_trait::async_trait;
use anvilml_core::{DeviceType, GpuDevice, HardwareInfo, HostInfo};
use crate::error::{HardwareError, Result as HwResult};
use crate::cpu::CpuDetector;

#[async_trait]
pub trait DeviceDetector: Send + Sync {
    async fn detect(&self) -> HwResult<Vec<GpuDevice>>;
    fn device_type(&self) -> DeviceType;
}

pub async fn detect_all_devices(config: &anvilml_core::config::HardwareOverrideConfig) -> Result<HardwareInfo> {
    let mut detectors: Vec<Box<dyn DeviceDetector>> = vec![Box::new(CpuDetector::new())];

    let mut all_devices = Vec::new();
    for det in &detectors {
        match det.detect().await {
            Ok(devs) => all_devices.extend(devs),
            Err(e) => tracing::debug!("Detector {:?} failed: {}", det.device_type(), e),
        }
    }

    // Build HostInfo from CpuDetector data
    let host = CpuDetector::new().host_info();

    Ok(HardwareInfo { host, devices: all_devices })
}
```

#### 2d. Create `src/cpu.rs`
```rust
use anvilml_core::{DeviceType, GpuDevice, HostInfo, InferenceCaps};
use async_trait::async_trait;
use sysinfo::System;
use crate::detector::DeviceDetector;
use crate::error::Result;

pub struct CpuDetector {
    host_info: HostInfo,
}

impl CpuDetector {
    pub fn new() -> Self {
        let mut sys = System::new_all();
        sys.refresh_cpu_all();
        sys.refresh_memory();

        let total_mem_mib = sys.total_memory() / (1024 * 1024);
        let free_mem_mib = sys.available_memory() / (1024 * 1024);
        let cpu_name = sys.cpu_name().to_string();
        let physical_cores = sys.physical_core_count().unwrap_or(1) as u32;
        let logical_threads = sys.logical_cpu_count() as u32;
        let cpu_usage = sys.cpus().first().map(|c| c.cpu_usage()).unwrap_or(0.0);

        Self {
            host_info: HostInfo {
                system_ram_total_mib: total_mem_mib,
                system_ram_free_mib: free_mem_mib,
                cpu_model: cpu_name,
                cpu_physical_cores: physical_cores,
                cpu_logical_threads: logical_threads,
                cpu_usage_percent: cpu_usage,
            },
        }
    }

    pub fn host_info(&self) -> HostInfo {
        self.host_info.clone()
    }
}

#[async_trait]
impl DeviceDetector for CpuDetector {
    async fn detect(&self) -> Result<Vec<GpuDevice>> {
        Ok(vec![GpuDevice {
            index: 0,
            name: self.host_info.cpu_model.clone(),
            device_type: DeviceType::Cpu,
            gfx_arch: None,
            vram_total_mib: self.host_info.system_ram_total_mib,
            vram_free_mib: self.host_info.system_ram_free_mib,
            vram_used_mib: 0,
            rebar_enabled: false,
            driver_version: "n/a".to_string(),
            capabilities: InferenceCaps {
                fp16: false, bf16: false, fp8: false,
                flash_attention: false, hipblaslt: false,
            },
        }])
    }

    fn device_type(&self) -> DeviceType {
        DeviceType::Cpu
    }
}
```

## Risk Assessment

| Risk | Mitigation |
|------|-----------|
| `sysinfo` API changes across versions | Pin to a specific version (0.32.x), test on dev machine |
| `async-trait` overhead | Minimal — only used for the trait, not in hot paths |
| `HardwareOverrideConfig` not directly importable | It's in `anvilml_core::config`, import via full path or re-export |
| sysinfo on Linux vs Windows | `sysinfo` is cross-platform, but verify refresh behavior on both |
| CPU usage measurement accuracy | Use first CPU core's usage as approximation; acceptable for MVP |
