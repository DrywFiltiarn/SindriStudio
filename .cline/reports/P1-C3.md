## What Was Implemented

### 1. `backend/worker/worker_main.py` — Modified

**Shutdown handler fix:**
- `handle_shutdown()` now accepts `worker_id` and emits a `Dying { worker_id, reason }` event via `write_event_safe()` before calling `sys.exit(0)`
- The `reason` field is set to `"Received Shutdown message"` per IPC protocol spec
- `read_loop()` now receives `worker_id` as a parameter

**MemoryReport background thread:**
- New `_memory_report_thread(worker_id, stop_event)` daemon thread running every 10 seconds
- Emits `MemoryReport` events with correct `worker_id`, VRAM fields (non-negative integers), `ram_pinned_mib=0`, `loaded_models=[]`
- Clean shutdown via `threading.Event` — main thread signals and joins after read loop exits
- Uses `query_memory_report(worker_id)` helper function for mock/real mode support

**Thread safety:**
- New `_write_lock = threading.Lock()` to protect stdout.buffer writes
- New `write_event_safe(event)` wrapper used by both the MemoryReport thread and Shutdown handler
- The main read loop still uses direct `write_event()` (single-threaded path)

### 2. `backend/worker/tests/test_worker_messages.py` — Created

**9 subprocess-based tests across 4 test classes:**

| Test Class | Tests | Description |
